# A股场景与规则核验

规则随市场、板块、证券类型和日期变化。先核沪/深/北交易所、主板/科创板/创业板、风险警示/退市整理/新股或恢复上市等状态，再查现行规则、实施通知与证券当日公告；规则已发布也可能部分暂缓实施。本文件不给通用默认涨跌幅或交易权限。

| 场景 | 关键资料 | 研究中必须保留的边界 |
|---|---|---|
| 当日买入后需退出 | 证券类型、回转规则、账户可卖数量 | A股股票与各类ETF不可混套；可提交委托不等于能成交 |
| 连续跌停/停牌/跳空 | 当日状态、成交量、排队、公告与复牌条件 | 止损价不是最大损失，延迟成交会改变退出价格；理论逐日跌幅不是终局下界 |
| 融资持仓 | 券商合同、担保/集中度、折算率、负债及追保条款 | 路径中触发强平与最终资产价格分开，合同规则未知不能套固定阈值 |
| ST/退市/财务更正 | 交易所规则、公司公告、审计意见、处罚/更正 | 风险警示不自动等于退市，未警示不等于无退市风险；避免事后回填标签 |
| 控股股东质押/增持/回购 | 质押比例与期限、公告、执行进度和资金来源 | 公告计划不等于完成，持股不证明与小股东承担相同损失 |
| ETF“分散” | 点时成份、权重、申赎/交易规则、折溢价与流动性 | 多只ETF可能同一行业/因子；场内卖出和赎回并非同一流程 |
| 期权或对冲 | 账户权限、合约、期限、乘数、费用、盘口、保证金 | 不假定能买单股期权、能融券或能按理论价平仓；对冲有基差和期限错配 |
| 现金需求或防守资产 | 必要支出日期、现金余额、产品信用/久期及可用时间 | 现金等价物不自动是本金保证，纸面资产不能当当日现金 |

来源优先顺序：交易所与监管现行规则/实施通知；公司和基金正式披露；券商合同与适用业务细则；授权行情和用户资料。搜索摘要与媒体只辅助定位，不认证合约或交易状态。

跨期复核保留原版本与当时可得资料。今日规则不应用于过去回测；新公告不证明原判断当时有证据。无法查当前规则时输出条件分析，不提供可执行交易参数。
