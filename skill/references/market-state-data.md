# 市场状态与风险承受能力分开

当用户问A股当下形态，先定义全A/某指数/某板块、研究日期与窗口。塔勒布框架用于检查风险机制，不是K线形态预测器；市场状态需要独立真实数据。

## 市场数据与图表

- 趋势：同日指数收盘/全收益序列、规范化净值和滚动回撤。可比较中证全指、沪深300、大小盘等，但标的/价格或全收益口径要一致。不凭单日涨跌定牛熊。
- 广度：点时股票池涨跌数、均线之上比例、新高/新低；停牌、退市、上市不足窗口和复权明确处理。不同分母不能比较成同一比例。
- 交易与杠杆：同市场成交额、换手率历史、融资余额和增量。成交不是净流入，融资余额变化不能单独认证风险偏好或资金方向。不要按涨跌给成交额贴主力流入标签。
- 波动与尾部：实现波动、下行极值、大跌数量、按具体板块/状态规则判定的跌停与成交约束。年化系数、窗口和有效交易日明确；不能把波动率或历史极值当未来损失上界。
- 估值：同指数同定义PE/PB/股息率及历史窗口，保留盈利/净资产版本、负盈利处理和缺失。板块平均PE不能直接当指数PE(TTM)或个股中位数，不能由截面得历史分位。

官方入口优先交易所数据、融资统计和指数公司资料，逐项记录范围、单位、观察/取得日与原始版本。只有单日或一个交易所，就明确局部覆盖，不宣布全A完整。

## 描述状态，不假装预测

用趋势、广度、流动性/波动压力分别描述，并列支持、反证和缺口。可说“所选窗口指数上行但广度收窄”，不能自动升级为牛市后期或确定顶部。普涨扩张/权重集中/下行压力等是原创条件描述，窗口和阈值需声明，状态转换需多期资料。

不把多个指标揉成无验证牛熊分数。不因市场上行判账户安全：仍需持仓因子、融资、现金需求和退出约束。市场信号与账户风险结论分别交付，缺一层数据不能用另一层代替。
