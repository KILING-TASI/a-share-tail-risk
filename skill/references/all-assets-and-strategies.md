# 全资产、负债与策略适用边界

核对日期：2026-10-15。以下是依据塔勒布问题意识形成的原创中国市场操作框架，不是作者对中国资产的推荐，也不保证收益。

## 先建立约束，而不是先挑资产

现金、存款、债券、股票、ETF、公募基金、理财、房地产、黄金、外汇、衍生品、企业股权和经营收入分别登记。经营收入是现金流，不能无依据资本化成可卖出资产；未来工资不能算立即可用现金。负债、担保、刚性支出和融资追缴单列。

每项保存金额、币种、估值依据和日期、可动用时间、期限、交易/赎回限制、质押、对手方、法律权利与资料缺口。统计口径之外的资产保留未知，不宣布掌握真实全部财富。先统一报告币种，汇率观察日和换算规则保留，不把账面价值当现金。

## 六种可借鉴的安排

| 安排 | 可研究的中国场景 | 关键约束与失败方式 |
|---|---|---|
| 避免毁灭，减少脆弱暴露 | 先隔离近期必须支付的资金，检查融资、担保与期限错配 | 不预设固定现金比例；长期债券、理财、房产不能自动成为立即可用现金 |
| 杠铃式风险安排 | 把必须保住的资金与最大损失可承受的小额试验分开研究 | 两端都要验证；高波动股票、可转债或黄金不是天然凸性。所谓低风险端也有信用、通胀、期限和流动性风险 |
| 有成本上限的选择权 | 比较买方期权、分阶段投资或可撤回经营试验的净收益形状 | 买方权利金可全损，续期与滑点侵蚀收益；ETF期权对单只股票有基差，资格和交易权限须另核。卖方义务不是买方有限损失 |
| 小额、可逆试错 | 研究/经营项目先用可承受的小预算验证，预先记录失败标准 | 试验次数、总损失和机会成本同时记录；不断补仓不能冒充有限成本试验 |
| 冗余与非预测准备 | 现金期限梯度、避免单一机构或单一收入来源成为致命依赖 | 名义分散可有共同信用、行业、币种和流动性冲击；相关性不是恒定保证 |
| 利益与损失绑定 | 审核基金、理财、管理人、荐股者或经营合伙人的责任安排 | 同投、锁定、追索与履约以文件为准；不由声誉、身份或口头保证推断可信 |

前三项的研究方向参见作者的 [反脆弱说明](https://www.fooledbyrandomness.com/Antifragile.htm)、[凸性与试错](https://fooledbyrandomness.com/ConvexityScience.pdf)及[毁灭风险讨论](https://www.fooledbyrandomness.com/precautionary.pdf)。这些文本不是A股收益验证。后续的资产映射和检查步骤属于本Skill原创操作化。

股票期权须满足适当性和权限条件，参见[上交所期权投资说明](https://one.sse.com.cn/onething/qqtz/)与[交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/option/c/c_20250610_10781448.shtml)。不能仅凭资金数额认定已合格，也不代用户下单。止损指令不能确保跌停、停牌或流动性不足时成交。

## 一手优先，证据逐项判定

1. 官方或合同一手：交易所、监管机构、统计发布者、公司正式公告、基金合同、本人账户/贷款合同。仍核观察期、发布时间、更正、口径与权利。
2. 对一手资料的原创计算：保存原始标识、单位、公式、参数与版本，不能称数据本身来自塔勒布。
3. 二手整理：授权数据商、行业协会或专业数据库，回查其原始来源；同一底层转载的两站不是两个独立证据。
4. 新闻、研报、社交线索：作为待核事实，不当作已证实价格、收益概率或动机。无法回溯时明确降低结论强度。

冲突数据不简单平均：先检查时间、对象、复权、净价/全价、税费、币种和修订。不因官网标签忽略错误，也不因二手来源而一律否定。许可、访问成功、数据完整和真实性是四个不同状态。
